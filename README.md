# Guia1 Backend Node Express

Proyecto backend desarrollado con Node.js y Express, como parte de la guia de Git y control de versiones del programa ADSO - SENA.
## Tecnologias utilizadas
- Node.js
- Express
## Como ejecutar el proyecto
1. Instalar dependencias: npm install
2. Ejecutar el servidor: node src/app.js
